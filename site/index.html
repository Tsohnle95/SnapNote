How do I install SnapNote?+

Download the Mac disk image, open it, and drag SnapNote into Applications. Launch it from there; it lives in your menu bar.

On first launch, allow Screen Recording in System Settings so SnapNote can capture the region you select.

What if macOS won’t open it?+

This first release is ad-hoc signed and isn’t Apple-notarized. If macOS blocks it, open System Settings → Privacy & Security after attempting to launch it, then choose Open Anyway for SnapNote.

Only approve the app if you downloaded it from the linked SnapNote GitHub release.

Which Macs does it work on?+

The download is for Apple silicon Macs (M1 or later) running macOS 12 or newer. Intel, Windows, and Linux downloads aren’t available.

Where do my screenshots go?+

By default, they’re saved in ~/screenshots/snapshot/. Each capture has its own folder with an image and your note. You can change the location in Settings.

Is it really free?+

Yes. Download it, use it, and explore the source on GitHub. There’s no subscription or account.
